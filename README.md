# Baga9898

Портал администратора - приложение, вмещающее в себе конфигурацию, информацию и управление приложениями.

## Необходимое окружение

> :warning: Перед началом установки убедитесь, что описанное ниже установлено:

- [Node.js v20 или свежее](https://nodejs.org/en/)
- [Git](https://git-scm.com/)

[!NOTE]
Для корректной работы линтера в сочетании с форматтером рекомендуется добавить следующие параметры с представлеными значениями в настройки вашего IDE/редактора кода (например, в VSCode за это отвечает файл `settings.json`):

```
"editor.defaultFormatter": "esbenp.prettier-vscode",
"editor.formatOnPaste": true,
"editor.formatOnSave": true,
"editor.formatOnType": true,
"editor.tabSize": 2,
"editor.codeActionsOnSave": {
  "source.fixAll.eslint": "explicit"
},
"eslint.validate": [
  "javascript",
  "javascriptreact",
  "typescript",
  "typescriptreact"
],
```

## Запуск приложения

### Установка зависимостей

После того как вы скачали репозиторий на локальную машину необходимо перейти в корневую папку проекта, открыв ваш любимый терминал и выполнить следующую команду:

```
npm install
```

### Запуск проекта локально (для разработки)

После установки зависимостей для запуска локального сервера необходимо выполнить команду старта проекта:

```
npm run dev
```

В случае отсутствия ошибок и успешного подъёма проекта будет запущен сервер, перейти на который можно по ссылке: [http://localhost:3000/](http://localhost:3000/)

### Сборка проекта

Для сборки проекта локально необходимо выполнить команду:

```
npm run build
```

После выполнения которой в корневой директории проекта будет создана папка `dist`, содержащая в себе файлы, подготовленные к стендовой среде, проверить работу и целостность которых возможно выполнив команду :

```
npm run preview
```

Которая запустит локальный сервер на порту [http://localhost:5000/](http://localhost:5000/)

## Скрипты

- dev - локальный запуск приложения для разработки на [http://localhost:3000/](http://localhost:3000/);
- build - сборка приложения;
- preview - запуск проекта из папки `dist` на [http://localhost:5000/](http://localhost:5000/);
- lint - вывод всех текущих замечаний линтера `eslint` со списком замечаний, возможных к исправлению линтером и нуждающихся в мануальном исправлении разработчиком;
- lint:fix - исправление замечаний линтера `eslint`, возможных к автономному исправлению;
- format - исправление замечаний форматтера `prettier`;
- format:check - вывод всех текущих замечаний форматтера `prettier`
